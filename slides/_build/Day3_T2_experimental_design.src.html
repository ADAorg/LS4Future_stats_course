Design beats analysis.

Pseudoreplication, batch effects, blocking and randomisation: the mistakes no statistical test can fix afterwards.

Day 3 · Topic 2 · Practical statistics for biomedical researchers
Everything so far assumed the data came from a sensible design. This session is about the decisions made before the first measurement. "To consult the statistician after an experiment is finished is often merely to ask him to conduct a post mortem examination" (Fisher, 1938). Every slide is a simulation where we know the truth.

What is n?

The treatment is…
EXPERIMENTAL UNIT
n PER GROUP
MEASUREMENTS PER GROUP

The lecture · notebook section A
Same animals, same cells, three different experiments. The experimental unit is the smallest thing that could independently receive a different treatment. Drug in the drinking water: the whole cage gets it, so cages are the units, n = 3 per group, whatever you measure inside them. Injection with mice randomised within cages: each mouse is a unit, and the cage becomes a block. One mouse per group: n = 1, and no number of cells fixes that; any difference could be that mouse.

More cells, more false positives.

Cells per mouse

The lecture · notebook section A
3 control and 3 treated mice; the treatment does nothing. Mice differ from each other as much as cells within a mouse do (ICC = 0.5). The cell-level t-test treats 150 cells as 150 independent patients: its standard error is far too small, so it is "significant" in most experiments. The test on mouse averages stays at 5%. Change cells per mouse and run again: the cell-level error rate gets worse with more cells, because the extra precision is about each mouse, not about mice in general.

Your effective sample size.

ICC: how alike are cells from the same mouse?
DESIGN EFFECT

neff = (mice × cells) / [1 + (cells − 1) × ICC]

However many cells you measure, neff never exceeds mice / ICC. To gain information, add animals.

The lecture · why it happens
The intraclass correlation (ICC) is the share of the total variation that lies between mice. With ICC = 0.5, after a handful of cells each extra cell adds almost nothing: the curves flatten at mice / ICC. Doubling the mice doubles the ceiling. Slide the ICC down: if mice really were nearly identical, cells would carry more information; but you rarely know that, and a mixed model or mouse means handle both cases correctly.

When treatment and batch line up.

Design

The lecture · notebook section B
12 samples, 6 per run; run B reads 1.5 units higher; the treatment does nothing. Confounded: controls in run A, treated in run B. Look at the design matrix: the treatment column and the batch column are identical, so no model can tell them apart. The false-positive rate is about 64%, and adding batch to the model is impossible: the software will drop a column or refuse. Balanced: every run has 3 of each; batch no longer biases anything, and including it in the model removes its noise and increases power.

Blocking: compare like with like.

How different are donors? (block SD)

The lecture · notebook section C
Six donors, each giving one control and one treated dish; the true effect is +1. Every line rises: within a donor the treatment effect is obvious. But donors differ, so the clouds of control and treated values overlap, and an unpaired test sees mostly donor noise. The paired test (or a model with + donor) compares each donor with itself: its power doesn't depend on donor variation at all. You saw the same thing with real data on Day 2: airway with cell line as the block gave about 40% more significant genes.

Randomise, or bias creeps in.

Allocation
The lecture · notebook section D
20 mice; heavier mice have higher outcome values; the treatment does nothing. "First caught": heavier, slower mice tend to be caught first, so the treated group is heavier, and the estimated effect is shifted by about +1 in every experiment: 40% false positives. Random allocation removes the bias. Matched pairs (rank by weight, pair neighbours, flip a coin within each pair) also removes it and makes the estimate more precise: blocking and randomisation together. Randomisation also balances what you didn't measure.

Then: "All my controls were sequenced in run 1 and all treated samples in run 2. Can I fix this with batch correction?"

Watch for:

  • fixes that keep n = 150: "use a Mann–Whitney test", "report the SEM of the cells"
  • "use a mixed model" with no warning that it still has only 3 mice per group
  • "ComBat can remove the batch effect" for a fully confounded design

A good answer:

"Yes. The mouse is the experimental unit, so n = 3 per group. Average the cells per mouse and compare 3 vs 3 (or fit a mixed model with mouse as a random effect); expect a much larger p-value. Report the number of mice and cells separately. For more power, add mice, not cells."
AI as tutor · built-in failure points
Most tutors get the diagnosis right and the fix half right. The batch question is the sharper test: a good answer says no correction can separate treatment from batch here, and proposes re-running a subset of samples across runs.

Five questions before the first sample.

  1. What does the treatment get applied to? That is your n.
  2. What else varies a lot (donor, litter, day, plate)? Block on it.
  3. Is every condition in every batch?
  4. How is allocation randomised, and who is blinded?
  5. Which analysis matches this structure? Decide it now.
